# MedEase — сайт клиники с онлайн-записью

Django-проект многопрофильной клиники: направления, врачи с графиком работы,
онлайн-запись на свободное время, личный кабинет пациента и панель врача.

## Возможности

**Пациент**
- регистрация с подтверждением почты (6-значный код), вход по логину или email, восстановление пароля;
- поиск врачей по имени и направлению;
- запись на приём: видны только свободные слоты в графике врача, занятое время недоступно;
- «Мои записи»: предстоящие приёмы, история, отмена записи, заключение врача после приёма;
- медицинская карта: дата рождения, пол, группа крови, аллергии, хронические заболевания.

**Врач** (аккаунт привязывается к врачу в админке)
- панель: сегодня / предстоящие / ждут подтверждения / история, статистика;
- подтверждение и отмена записей, неявка;
- карточка приёма: жалобы, медкарта пациента, прошлые приёмы, заключение и завершение приёма.

**Администратор** (`/admin/`)
- направления, врачи и их график работы (по дням недели), длительность приёма, стоимость;
- записи с фильтрами и массовыми действиями, заявки на консультацию, пациенты с медкартой.

## Запуск

```bash
python -m venv env
env\Scripts\activate          # Windows
pip install -r requirements.txt
copy .env.example .env        # и заполните значения
python manage.py migrate
python manage.py createsuperuser
python manage.py seed_demo    # график работы врачам без графика (Пн–Пт 9–17, Сб 9–14)
python manage.py runserver
```

Если в `.env` не указаны `EMAIL_HOST_USER` и `EMAIL_HOST_PASSWORD`, письма (коды подтверждения)
выводятся в консоль сервера.

## Как сделать врача

1. Создайте пользователя (или пусть врач зарегистрируется на сайте).
2. В админке → «Врачи» → выберите врача → поле «Аккаунт врача».
3. В том же окне заполните «График работы» — без графика онлайн-запись к врачу недоступна.

## Тесты

```bash
python manage.py test
```

## Структура

| Приложение | Что внутри |
|---|---|
| `blog` | главная, направления, расписание, контакты (заявки), общие стили |
| `doctors` | направления, врачи, график работы, панель врача |
| `appointments` | запись на приём, слоты (`services.py`), статусы, заключения |
| `accounts` | регистрация, вход, профиль и медицинская карта |
| `templates/` | все HTML-шаблоны |

Данные клиники (телефон, адрес, часы работы) — в `main/settings.py`, словарь `CLINIC`.
